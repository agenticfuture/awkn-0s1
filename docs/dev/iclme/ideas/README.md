# Ideas Convention

Each idea in this folder should use its own subfolder.

Recommended structure:

```text
ideas/
  <idea_name>/
    prompts.md
    notes.md
    changes/
```

Guidelines:

- Use a short, readable snake_case folder name.
- Save the original request or prompt in `prompts.md`.
- Capture follow-up thinking, decisions, or rough plans in `notes.md`.
- Store implementation notes or change-specific artifacts in `changes/`.
